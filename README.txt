ASHHUUU — BIRTHDAY WEBSITE
==========================

WHAT'S INCLUDED
- index.html: the complete responsive birthday website
- photos/: put your pictures here
- music/: put your chosen MP3 here

PREVIEW
Double-click index.html to open it in your browser.

ADD YOUR PHOTOS
1. Copy your chosen pictures into the photos folder.
2. Open index.html in a text editor.
3. Find the gallery section. Replace each placeholder div with an image tag.
   Example:
   <img src="photos/photo1.jpg" alt="Our favourite memory">
4. Change the caption below each photo to your real memory.
   Suggested filenames: photo1.jpg, photo2.jpg, photo3.jpg, etc.

ADD BACKGROUND MUSIC
1. Add an MP3 file you have the right to use to the music folder.
2. Rename it exactly: your-song.mp3
3. The Play our song button will play it after the visitor taps it.
   (Browsers generally block autoplay until the visitor interacts.)

PERSONALISE THE WORDS
Open index.html and search for:
- "Dear Ashhuuu" to edit the letter
- "The endless conversations" to edit the memory cards
- "You are very, very loved" to edit the surprise
- "Always in your corner" to change the sign-off

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in or create an account at https://github.com
2. Click the + menu (top right) > New repository.
3. Name it ashhuuu-birthday and choose Public. Create the repository.
4. In the new repository, choose Add file > Upload files.
5. Upload index.html and the photos and music folders (with their contents).
   Keep index.html at the top level of the repository, not inside another folder.
6. Click Commit changes.
7. Open the repository's Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose branch main and folder /(root), then Save.
10. Wait a few minutes, then refresh Settings > Pages. Your website link will appear there.
    It will look like https://YOUR-USERNAME.github.io/ashhuuu-birthday/

IMPORTANT PRIVACY NOTE
GitHub Pages websites are public on the internet. Anyone with the link may view it,
and the source repository is public on GitHub Free. Only upload photos and details
you are both comfortable having online. Avoid private or sensitive photos.
